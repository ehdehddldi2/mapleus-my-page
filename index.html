📊 메이플어스 공식 확률 자료

공식 확률 공시는 현재 게임에 적용되는 값을 보여 주며, 실제 확률 확인은 실서비스 누적 기록을 집계합니다. 아래 계산기는 공식 수치를 임의로 고정하지 않습니다.

📜 공식 확률 공시 ↗📈 실제 확률 확인 ↗⭐ 스타포스 실제 기록 ↗

큐브는 등급 상승 확률·보장 횟수·2~3번째 줄 등급·장비 레벨별 옵션 확률을 따로 확인해야 합니다. 실제 통계는 과거 기록이므로 다음 시도의 성공을 보장하지 않습니다.

⭐ 스타포스 목표 달성 예상 비용 3.3

공식 공시에서 해당 장비의 단계별 성공·유지·하락·파괴 확률을 확인해 붙여넣으세요. 공식 수치는 서버에서 변경될 수 있으므로 자동으로 임의 입력하지 않습니다. 파괴 시 계산을 종료하는 파괴 전 목표 달성 확률과, 파괴 시 시작 단계로 복구해 재도전한다는 가정의 기대 비용을 계산합니다.

한 줄에 현재 성,성공%,유지%,하락%,파괴% 입력. 예: 0,95,5,0,0는 입력 형식 예시일 뿐 실제 확률이 아닙니다. 목표까지 모든 단계가 필요합니다.

공식 스타포스 확률표
공식 단계별 확률을 입력하면 계산합니다.

계산 가정: 실패(하락)는 1성 하락(0성 아래로 내려가지 않음), 파괴 시 복구하여 시작 성부터 재도전, 스타캐치·파괴 방지·찬스 타임은 입력 확률에 이미 반영된 경우에만 적용. 단계별 실제 강화 비용이 다르면 단일 비용 입력은 참고치입니다.

🎲 큐브 천장 포함 기대 비용 3.3

공식 큐브 종류·현재 등급에 해당하는 1회 상승 확률과 등급 상승 보장 횟수를 입력하세요. 이미 누적된 실패 횟수도 반영합니다.

공식 큐브 확률을 입력해 주세요.

등급 상승 1단계 기준. 목표 옵션 2줄·3줄 획득 확률과 블랙 큐브 결과 선택 여부는 포함하지 않습니다.

🎲 큐브 등급 상승 확률 참고 계산

공식 공시에서 해당 큐브·현재 등급의 상승 확률을 직접 확인해 입력하세요. 독립 시행을 가정한 참고 계산으로, 천장·옵션 출현 확률은 반영하지 않습니다.

※ 보장 횟수에 도달하면 실제 확률 구조가 달라집니다. 특정 잠재옵션 2줄·3줄을 얻을 확률은 이 계산 결과와 다릅니다.

실제 메이플어스 서버 옵션 효율·토드 가능 여부는 확인되지 않았어요. 아래 계산은 입력값 비교와 비용 합산용입니다.
